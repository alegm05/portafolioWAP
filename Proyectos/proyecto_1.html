[PRJ_01]

Ficha Técnica

De la teoría a la práctica: walkthrough en acción (guía y video)

Demostración práctica de las técnicas y metodologías utilizadas para evaluar y vulnerar la máquina virtual "digitalworld.local: Snakeoil" en un entorno controlado.

El proceso abarca desde la recolección inicial de información hasta el compromiso total del sistema, logrando acceso administrativo (root) e ilustrando los riesgos asociados a las configuraciones vulnerables y la falta de sanitización de entradas en servicios web.

OBJETIVO DE EVALUACIÓN

Máquina Virtual "Snakeoil" (Debian 10)
Descarga VulnHub: digitalworldlocal-snakeoil (v738)

TOPOLOGÍA DEL LABORATORIO

• Máquina Atacante: Kali Linux (Modo Host-Only / Solo anfitrión)
• Máquina Víctima: Snakeoil VM (Debian 10)
• Aislamiento: Red virtual privada sin acceso a infraestructuras externas

[PHASES_03]

Walkthrough

1. Reconocimiento y Enumeración

Descubrimiento del segmento de red e identificación de puertos y versiones de servicios activos mediante herramientas de escaneo perimetral:

Puerto Protocolo Servicio Versión Detectada / Estado
22 TCP SSH OpenSSH 7.9p1 (Debian)
80 TCP HTTP Nginx Web Server
8080 TCP HTTP-Alt Nginx (Portal Good Tech Inc.'s Snake Oil Project)
2. Análisis de Vulnerabilidades

Exploración de directorios mediante herramientas de fuerza bruta (Gobuster) que expuso los endpoints /users (revelando nombres de usuario y hashes PBKDF2) y el endpoint administrativo /run, el cual presentó vectores de inyección de comandos en el backend al procesar parámetros HTTP POST no sanitizados.

3. Explotación y Acceso Inicial

Construcción del vector de inyección de comandos mediante peticiones POST dirigidas hacia el servicio web, logrando la ejecución arbitraria de comandos en el sistema operativo y el posterior establecimiento de una reverse shell interactiva hacia el equipo atacante.

4. Post-Explotación y Escalada de Privilegios

Inspección interna de la máquina virtual (Debian 10) orientada a detectar configuraciones deficientes, permisos inapropiados o debilidades de elevación local para alcanzar el nivel de superusuario (root) y validar el compromiso total del sistema.

>_ Interfaz de autenticación de la máquina virtual Snakeoil (Debian 10) en VirtualBox.

[CONC_04]

Conclusión

El desarrollo de este walkthrough evidenció que la explotación de entornos reales demanda una metodología técnica sistemática y flexible. Cuando el análisis criptoanalítico sobre hashes complejos consume tiempo o capacidad de procesamiento inviable, el analista debe pivotar hacia fallos de validación en la lógica de negocio y en las interfaces de comunicación.

Las brechas identificadas en la máquina Snakeoil ratifican que la robustez de un sistema no depende únicamente del uso de algoritmos criptográficos modernos, sino de la sanitización exhaustiva de cada parámetro de entrada, el principio de menor privilegio en los servicios expuestos y la actualización periódica de la infraestructura corporativa.
