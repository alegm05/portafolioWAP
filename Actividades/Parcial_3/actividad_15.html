Actividad 15: La fotografía como testigo

Extracción de metadatos GPS para geolocalización. Práctica forense digital centrada en la recolección, interpretación y purgado de datos ocultos (EXIF) en documentos ofimáticos e imágenes digitales utilizando ExifTool.

HERRAMIENTAS

Software: ExifTool (CLI / GUI)
Muestras: WOA database application form.docx, XiaomiMiA2Lite.jpg

OBJETIVO TÉCNICO

Extraer metadatos para perfilar la autoría de un documento (fechas, creadores, plantillas) y extraer coordenadas GPS incrustadas en una fotografía para realizar una geolocalización inversa (OSINT). Finalmente, aplicar técnicas de sanitización de archivos (borrado de metadatos).

[PART_I]

Análisis .DOCX

Parte I: Fichero "WOA database application form.docx"

Evaluación de las propiedades internas del documento de Word para rastrear su origen y ciclo de edición.

1. Categorización del archivo INTERPOL
exiftool -InterpolClassification "infocrim\WOA database application form.docx"
InterpolClassification : Unclassified

R= Unclassified

2. Plantilla (Template) utilizada
exiftool -Template "infocrim\WOA database application form.docx"
Template : G03 Basic Doc SP.dotx

R= G03 Basic Doc SP.dotx

3. Tiempo total de edición
exiftool -TotalEditTime "infocrim\WOA database application form.docx"
Total Edit Time : 45 minutes

R= 45 minutos

4. Compañía propietaria y Autoría
exiftool -Company "infocrim\WOA database application form.docx"
Company : OIPC - INTERPOL

exiftool -Creator "infocrim\WOA database application form.docx"
Creator : Carolyn Lejeune

exiftool -LastModifiedBy "infocrim\WOA database application form.docx"
Last Modified By : Carolyn Lejeune

R= Compañía: OIPC - INTERPOL. Creador y última modificación: Carolyn Lejeune.

5. Fecha de creación original
exiftool -CreateDate "infocrim\WOA database application form.docx"
Create Date : 2019:05:03 15:35:00Z

R= 03 de mayo del 2019

[PART_II]

Metadatos EXIF

Parte II: Fichero "XiaomiMiA2Lite.jpg"

Extracción de huellas digitales de hardware, configuraciones de cámara y coordenadas geoespaciales ocultas en la imagen.

Parámetros de Captura
  • > ISO: 100
  • > Longitud Focal: 3.8 mm
  • > Flash: Off, Did not fire
  • > Dispositivo: Xiaomi Mi A2 Lite
  • > Fecha de captura: 28 de mayo del 2020 (2020:05:28 18:11:41)
Extracción de Coordenadas GPS
exiftool -GPSPosition "infocrim\XiaomiMiA2Lite.jpg"
GPS Position : 51 deg 15' 12.99" N, 0 deg 32' 21.93" W

R= 51° 15' 12.99" N, 0° 32' 21.93" W

>_ OSINT: Trazado de las coordenadas GPS extraídas en Google Maps (Guildford, Reino Unido).

Sanitización de Archivos

Para garantizar la privacidad y prevenir fugas de información, se procede a eliminar la totalidad de los metadatos incrustados en la fotografía.

exiftool -all= "infocrim\XiaomiMiA2Lite.jpg"
1 image files updated

Tras la ejecución del comando, una verificación posterior confirma que atributos como la fecha original, GPS, fabricante y modelo de cámara han sido eliminados de la estructura del archivo, reduciendo el tamaño del fichero a información puramente gráfica.
