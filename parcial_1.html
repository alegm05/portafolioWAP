No presiones Esc… todavía

Desarrollo de un script en Python empleando la librería pynput para la implementación de event hooks y callbacks. Cada registro se estructura con asociación temporal precisa en milisegundos y un identificador secuencial, permitiendo analizar el comportamiento base de las técnicas de captura de entrada.
